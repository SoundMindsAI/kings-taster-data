# Sources and licenses (kings-taster-data)

Checked on 27 November 2026 against each source's own published terms.
This table is the public licensing table. Only sources listed here are described
publicly. The same rows live in `licensing.json`, which the tests check against
this file and against the list-file fetchers.

Sources in the **list file** are fetched by the pipeline and republished, with
only the fields named in SPEC.md §6.1. **Live lookups** happen from each installed
bot and are never copied into the list file. **Test data** is bundled only in
`conformance.json`.

**What the list file keeps.** For CISA KEV: `cveID`, vendor and product (pattern-checked), `dateAdded`, and known ransomware use. Never `vulnerabilityName`, `shortDescription`, `requiredAction` or `notes`. For OpenSSF `MAL-` records: ID, package name, versions or ranges, aliases (ID pattern only), `published`, `modified`, and origin source names. Never `summary`, `details`, `references` or `credits`. Third-party links inside a source keep their own terms; we don't copy them.

**Our own code and data format:** MIT (see `LICENSE`). Each list entry stays under its source's terms and carries its own `license`, `attribution`, `upstream_origin` and `source_url`.
