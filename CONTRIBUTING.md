# Contributing to kings-taster-data

Thank you for wanting to help. This repo holds King's Taster's signed list, its pipeline and its spec, so we
keep every change in our own hands.

## We don't accept outside pull requests

This repo is read-only to the public. Pull requests from anyone outside SoundMinds are closed automatically,
with a comment pointing here. Please don't open one, even for a typo. Tell us in an issue instead and we'll make
the change ourselves.

## A wrong verdict or list entry

Open an issue in this repo. Say what was checked (the package and version, the repo, or the link written
defanged, for example `hxxps://example[.]com/`), what King's Taster answered, and why you think it's wrong.
Please don't include personal details, keys or anything private. We acknowledge within 2 business days. A wrong
entry is revoked in the next signed list, or right away if it's urgent.

## A security flaw

Don't open a public issue. Report it privately as described in [SECURITY.md](SECURITY.md).

## Everything else

Questions and suggestions are welcome as issues.
